图提取 ImageGrab
功能 安装 注意 GitHub

一键提取电商详情页的所有图片

在淘宝、天猫、京东、拼多多的商品详情页扫描图片，自由勾选后批量下载，保留原始画质。

下载 ZIP 查看源码

Chrome 扩展，暂未上架应用商店，需以「加载已解压的扩展程序」方式安装。

功能

一键提取

详情页右下角注入悬浮按钮，点击工具栏上的扩展图标效果相同。

兼容懒加载

优先读取 data-src 等懒加载属性并解析 srcset，滚动后再提取结果更完整。

覆盖背景图

除 img 标签外还会扫描内联与计算样式里的 background-image。

自动去重

同一张图的尺寸后缀与查询参数会归一化合并，只保留分辨率最高的一张。

原图画质

直接下载图片原始地址，字节保持原格式不做转码，扩展名与真实格式一致。

连续编号

文件名形如 商品图_20261014_0001.jpg，编号跨批次连续，不会互相覆盖。

安装步骤

  1. 点上方「下载 ZIP」并解压，或执行 git clone https://github.com/SoulmateRW/plug.git。
  2. 打开 chrome://extensions，开启右上角的「开发者模式」。
  3. 点「加载已解压的扩展程序」，选择含 manifest.json 的那一层目录。
  4. 打开商品详情页，点右下角「获取图片」，在新打开的页面勾选后点「下载选中」，文件存入浏览器默认下载目录。

需要注意

  • 提取前先把页面滚到底，让懒加载的图片都加载出来，结果会更完整。
  • 图片字节保持原始格式，不做格式转码，因此不会出现「扩展名是 png、内容其实是 jpg」的情况。
  • 只采集当前页面，iframe 与 Shadow DOM 内部的图片不会被抓取。
  • 若某个图片 CDN 校验 Referer 做防盗链，下载会被拒绝并计入结果里的「失败 N 张」。
  • 改动任何文件后，需在 chrome://extensions 点击该扩展卡片上的刷新按钮重新加载。
