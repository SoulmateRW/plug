# 图提取 ImageGrab

Chrome Manifest V3 扩展：在淘宝、天猫、京东、拼多多的商品详情页一键提取图片，自由勾选后批量下载。

## 功能

- **一键提取**：详情页右下角注入「获取图片」悬浮按钮，点击工具栏上的扩展图标效果相同
- **兼容懒加载**：优先读取 `data-src`、`data-lazy-src`、`data-ks-lazyload` 等懒加载属性，并解析 `srcset` 取最高分辨率那一项
- **覆盖背景图**：除 `<img>` 外还会扫描内联 `style` 与计算样式里的 `background-image`，电商详情页的图文常以这种方式渲染
- **自动去重**：同一张图的不同尺寸后缀（`_400x400.jpg`、`_.webp`）与查询参数会归一化合并，只保留分辨率最高的一条
- **原图画质**：直接下载图片原始地址，字节保持原格式不做转码，扩展名按 URL 推断，与真实格式一致
- **连续编号**：文件名形如 `商品图_20261014_0001.jpg`，编号跨批次连续，重复下载不会互相覆盖
- **失败可见**：下载中断（如 403）会显示为「完成 X 张，失败 Y 张」；缩略图加载失败的卡片会被标记并禁止勾选

## 安装

1. 打开 `chrome://extensions`，开启右上角的「开发者模式」
2. 点击「加载已解压的扩展程序」，选择本项目根目录（含 `manifest.json` 的那一层）
3. 打开商品详情页，点击右下角的「获取图片」按钮，或点击工具栏上的扩展图标
4. 在新打开的图库页勾选需要的图片，点击「下载选中」，文件保存到浏览器的默认下载目录

## 使用提示

- 提取前先把页面滚到底，让懒加载的图片都加载出来，能得到更完整的结果
- 图库页支持「全选」「反选」与逐张勾选，取消全部勾选后下载按钮会置灰
- 改动任何文件后，需要在 `chrome://extensions` 点击扩展卡片上的刷新按钮重新加载；改过 `background.js` 还需重开一次 Service Worker

## 文件结构

| 文件 | 作用 |
| --- | --- |
| `manifest.json` | 扩展清单，声明权限、内容脚本与图标 |
| `background.js` | Service Worker，接收提取结果、写入本地存储、打开图库页 |
| `content.js` | 内容脚本，注入悬浮按钮并扫描页面图片 |
| `content.css` | 悬浮按钮与提示浮层的样式 |
| `gallery.html` | 提取结果页 |
| `gallery.js` | 结果页逻辑，勾选与批量下载 |
| `gallery.css` | 结果页样式 |
| `icons/` | 扩展图标 16/32/48/128 |

## 权限说明

| 权限 | 用途 |
| --- | --- |
| `storage` | 暂存提取到的图片地址与下载编号 |
| `downloads` | 批量保存图片 |
| `host_permissions` | 覆盖淘宝、天猫、京东、拼多多站点域名，以及图片所在的 `alicdn.com`、`360buyimg.com`、`jdimg.com`、`pddpic.com` CDN |

## 已知限制

- 只采集当前页面：iframe 与 Shadow DOM 内部的图片不会被抓取
- 不做格式转码，图片字节保持原始格式
- 若某个 CDN 校验 `Referer` 做防盗链，下载会被拒绝并计入失败数，此时需要引入 `declarativeNetRequest` 给请求补上来源站 `Referer`（当前实现未启用该权限）

## 开发

纯原生 JavaScript、无构建步骤、无第三方依赖，改完文件直接在 `chrome://extensions` 刷新即可。
